### CDR-2026-011: GitHub Actions Workflows and Reusable Actions (Rule)

Applies to `standards-audit.yml` + caller/sweep examples:
- `workflow_call` for reusable workflows; version/pin by Git tag or commit SHA
- Minimal `permissions` block; `contents: read` default; never over-grant
- `concurrency` groups to prevent duplicate runs
- Job timeouts and resource limits for cost control
- Test workflow changes in a test repo before promoting org-wide
- Never store long-lived credentials; prefer OIDC/keyless auth
- `actionlint` / UI validation to catch workflow syntax errors
